# AC-14/15：真实 HTTP 任务取消

`scripts/check-http-cancel.mjs` 启动真实 Java 21 服务进程、一个本地模拟 Anthropic Messages 服务，并连接专用可丢弃 PostgreSQL 18.6 数据库。模拟模型保持请求未完成，脚本通过 `/api/v1` 创建作品、章节和任务，再从 HTTP 取消任务；所有数据库访问都经过真实服务接口。测试结束后删除作品、停止 Java 进程并删除专用数据库。

运行中取消：首个模型请求保持未完成时，取消接口返回处理中或已取消状态；模型迟到响应释放后，任务最终为 `CANCELLED`，没有工具步骤、来源或建议，正文和版本保持不变。SSE 从 `afterSeq=0` 重放 `run.cancelled`。本次实际回执为 `RUNNING`，最终为 `CANCELLED`。

排队取消：另起两个作品的运行任务占满两个 Worker，第三个作品任务保持 `QUEUED`。对第三个任务发 HTTP 取消后立即得到 `CANCELLED`，SSE 可重放取消事件，模型请求数仍为三个；随后取消两个占槽任务并核对其终态。本次脚本在专用数据库通过，未使用真实模型密钥。

这覆盖了真实 HTTP 的取消及事件回放路径。浏览器按钮操作、网络断开后的界面恢复和实际提供方请求取消仍待独立验收。
