# 全局设置与 Skill 消息引用验证（2026-10-12）

## 实现

- 作品列表页、写作工作区打开统一全局设置；作品设定保持独立。打开设置保留正文草稿、对话输入与运行任务。
- 设置中的 Skill 库支持搜索、状态筛选、Markdown/ZIP/目录导入、启停、更新、编辑、版本与文件查看、导出、删除。
- 输入区支持引用按钮和 `$` 自动补全；引用随消息保存，以 skill ID 标识，删除引用同时移除结构化记录。
- 所有已启用 Skill 始终可发现。显式指定和自动发现均通过 `read_skill` 渐进加载；初始请求只包含摘要和引用。
- 显式指定的指导未进入后续模型请求时，依赖工具被拒绝，任务不能成功结束。执行详情仅展示实际加载项及其来源。
- V13 删除发现开关和对话固定表，增加消息引用字段；旧消息、版本包与 Run 使用记录保留。
- 改名前已插入的引用保留稳定 ID；失败重试保留原引用与版本，新任务使用当前版本。
