# 统一助手与按需上下文验证

日期：2026-10-12。依据：[实现设计](../design/unified-assistant-context.md)。

## 实现

- 新对话统一使用 ASSISTANT，移除输入区任务类型；快捷提示只填入指令。
- 编辑器当前章节是可清除、恢复的优先参考；发送时固定章节 ID、已保存版本和后端正文快照，正文按需通过工具读取，不默认注入模型。
- 用户明确指定其他章节时可检索、读取并为实际章节生成候选稿；无参考也能 search/read/propose。普通讨论不强制读整章。
- 修改必须完整读取对应正文并进入后续模型请求，同批次 read/propose、未读取目标及错误版本均被拒绝；候选稿独立携带目标与基准内容，完成事务再次校验证据。
- 历史消息展示当轮参考；建议卡片及正文查看绑定实际目标。切章不改变已受理对象，失败重试保留原参考版本。
- 不自动保存、读取未保存草稿；界面明确提示助手使用已保存版本。建议应用仍通过现有草稿、保存和版本冲突流程。
- V10 新增参考快照列、归属及版本外键，保留旧任务类型与原幂等摘要。

## 生效

需使用新版前后端；后端启动时由 Flyway 自动执行 V10。仅更新前端而仍运行旧后端，无法使用新消息上下文协议。
