# Agent loop HTTP 与工作台联调（2026-09-29）

## 实现范围

- 增加 Spring Boot 可执行入口，将已有 RunScheduler、内容服务、建议服务接入 `/api/v1`。模型未配置时内容接口保持可用，任务提交返回可读的 `MODEL_ERROR`。
- 增加作品、章节、设定与章节历史接口；正文保存采用版本条件更新，同事务写入不可变历史；目录与设定变更锁定作品并检查活动任务。
- 增加任务列表/详情、建议详情、受控 trace 查询。任务详情在 repeatable-read 快照中读取步骤与来源；来源仅在结果消息出现在已完成模型请求的输入引用中才标记为送达。
- 增加数据库事件游标 SSE；`Last-Event-ID` 优先于 `afterSeq`，仅发送已提交的 `seq > cursor` 事件，终态后关闭连接。
- 增加 React 工作台：草稿保护、正文保存与历史、设定维护、任务提交和停止、事件重连与轮询降级、执行记录、历史来源以及建议整体接受/拒绝。
- 正文与设定搜索加入 Java 截止检查和 PostgreSQL `statement_timeout`，查询上限受 5 秒及运行剩余时间约束。

## 验证

- Java 21 执行 `mvn -o -f backend/pom.xml verify -q`：18 个单元测试通过；PostgreSQL 18.6 上 5 个集成场景通过，另 2 个仅在显式本地 HTTP 测试开关下运行的适配器场景跳过。每个数据库场景使用独立 schema，迁移后清理。
- 在一次性 PostgreSQL 18.6 容器中启动可执行 JAR，实际 HTTP 请求通过：健康与能力查询、创建作品与章节、保存正文、旧版本冲突返回 409、读取历史 v1、创建设定、查询空任务列表、无 API key 时提交返回 503。
- Vite `npm run build` 通过；开发服务器实测 `/`、`/src/App.jsx` 与 `/api/v1/health`、`/api/v1/projects` 代理均返回 200。
