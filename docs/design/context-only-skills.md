# 上下文 Skill

2026-10-19：当前产品能力和验收依据；替代历史完整 Skill PRD 中的脚本执行范围。

## 能力与上下文

Skill 是动态加载的角色、方法和参考资料，不是独立进程或 Agent。名称和描述进入每轮固定版本的目录；用户 `$` 引用和自然语言指定均要求先读取指导，自动发现仍可同时使用其他相关 Skill。当前 main 已移除对话固定项和本轮版本选择，不能恢复旧的固定选择交互。

保留 `read_skill`、`read_skill_file`、8 个 Skill 加载上限、版本固定、分页、加载去重、真实请求送达标记和压缩后的指导恢复。脚本文件仅保存、预览和导出；读取工具不将其加载为 Skill 上下文。普通二进制文件仍返回受保护下载引用，不成为已读文本证据。

系统保留当前作品的 `read_project`、章节和设定 list/read/search 工具。创建或修改由 `propose_chapter_edit`、`propose_setting_edit` 提供候选稿；它们沿用统一助手的用户意图、项目范围、本轮读取与版本证据、作者审阅保存边界。加载 Skill 不改变工具集合，不新增逐 Skill 授权。

Skill 内容和 allowed-tools 等元数据不能授予权限；不执行代码、不安装依赖、不接外部服务、不访问任意本地文件或其他作品。上传校验仍拒绝越界路径、链接和损坏文本。兼容性提示识别脚本文件及部分显式依赖/工具声明，不承诺理解自然语言中的所有不兼容要求。

## 前端与文档

设置 → Skill 的导入入口前简要说明能力范围，提供“如何创建 Skill”。指南在同一设置面板内切换，返回保留搜索、选中文件、添加区和未保存编辑。无额外导入确认步骤。包详情显式展示不支持能力及脚本文件清单，不暗示导入即全部可用。

[用户指南](../user-guide/skills.md) 是唯一维护源，前端构建时直接引入，README 链接同一文档。指南说明工具用途和限制，提供人物审稿模板、复制和下载；模板也通过实际包校验测试。

## 运行、存储与升级

删除 run_skill_script、执行器 HTTP 端口与实现、Python/Node 容器调度。新部署不包含 skill-executor、Docker socket 或 execution 网络；CI 仅构建 backend/web 两镜像，发布 deploymentContract 2。

完整不可变包、版本引用和历史对话不变。返回版本兼容性时依据当前策略重算，旧包即使记录过可执行环境，也只展示上下文能力，无需数据迁移或修改旧包。历史执行表、下载接口和已有产物到期维护保留；启动将旧 STARTED 记录明确失败，不恢复执行。新任务不会生成脚本执行或产物。

部署程序保留 contract 1 记录的停止、恢复和健康检查兼容，用原 Compose 恢复旧环境。新候选删除旧执行器配置。备份按实际运行服务停止写入，保留数据库、版本包和有效历史附件；文件验证用宿主机 Python 和临时数据副本。首次升级须同步宿主机部署程序及 Compose，不能仅发布新镜像。

## 验收

- 新模型请求只有两个 Skill 读取工具，同时保留作品基础工具。
- 自动发现、用户引用、固定版本、分页、压缩恢复和送达校验继续通过现有集成测试。
- 含脚本及不支持工具声明的包可保存/完整导出；新旧版本均展示当前限制，不产生执行记录。
- 用户在指南和库之间切换保留草稿，复制/下载的模板可导入，能力提示无需额外确认。
- 新两镜像候选无执行器；旧三镜像记录仍可用于失败恢复；备份不向不存在的服务发送停止命令。
